# Femi Tewogbola: Portfolio

My personal portfolio site: about me, experience, skills grouped by how I have used them, and the projects I have built while moving into cloud and DevOps.

Live site: https://femitewo.github.io/

## What is in here

- `index.html`, `style.css`, `script.js`: the single-page portfolio (plain HTML, CSS and JavaScript, no build step)
- `currency_converter/`: a currency converter that uses the free open endpoint of [ExchangeRate-API](https://www.exchangerate-api.com)
- `Forecaster/`: an early charting project on a sample fuel and energy price dataset, with a simple growth-rate projection, built with Chart.js
- `404.html`: custom page-not-found page

## Related projects

- [ansible-aws-lab](https://github.com/FemiTewo/ansible-aws-lab): step-by-step Ansible tutorial on AWS
- [devops-scripts](https://github.com/FemiTewo/devops-scripts): Linux, Bash and AWS practice scripts
- [energy-forecaster](https://github.com/FemiTewo/energy-forecaster): 7-day solar and wind forecast for any city

## Run it locally

Open `index.html` in a browser. An internet connection is needed for fonts, icons and the live data in the demo apps.
